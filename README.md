# مركز التحليل الذاتي

## الرفع على GitHub
ارفع **الملفات الأربعة مباشرة في جذر المستودع** وليس داخل مجلد:
`app.py` · `requirements.txt` · `render.yaml` · `README.md`

المشروع كله في `app.py` واحد، ولا توجد مجلدات داخلية ولا استيرادات محلية.

## النشر على Render
1. Render ← New ← Blueprint ← اختر المستودع.
2. أدخل `ADMIN_PASSWORD` (كلمة مرور اللوحة)، واختيارياً `TELEGRAM_TOKEN` و`TELEGRAM_CHAT_ID`.
3. بعد Live افتح الرابط. استخدم UptimeRobot على `/health` كل 5 دقائق لتقليل خمول الخدمة.

## ربط TickerAll (حساب MT5 تجريبي على Exness)
1. أنشئ مفتاح API من لوحة TickerAll (يبدأ بـ `cf_api_`).
2. من لوحة الإعدادات: أدخل المفتاح، ورقم الحساب التجريبي، والسيرفر (مثل `Exness-MT5Trial16`)، وكلمة المرور.
3. اضغط **اتصال واختبار الرموز**. النظام يتحقق أن الحساب تجريبي، ويعرض رموز الذهب والبيتكوين المتاحة.
4. اختر وضع **MT5 تجريبي** ثم **تطبيق الوضع المختار**.

### ما يحدث عند الصفقة
- يُرسل أمر السوق مع الوقف والهدف إلى TickerAll، فيحميهما الوسيط حتى لو كان Render نائماً.
- عند إغلاق الصفقة على المنصة يسجّل النظام ربحها أو خسارتها من سجل المنصة.
- المراكز المفتوحة على الحساب من غير النظام تظهر في قسم "غير مُدارة" ولا يفتح النظام مركزاً آخر على الرمز نفسه.

## أوضاع التنفيذ
| الوضع | الوصف | الحالة |
|---|---|---|
| ورقي | صفقات وهمية محاكاة محلياً | مفعّل دائماً |
| MT5 تجريبي | حساب Exness تجريبي عبر TickerAll | يتطلب بيانات TickerAll |
| Binance Testnet | أموال وهمية، للبيتكوين فقط | يتطلب مفاتيح Binance |
| حقيقي | تنفيذ بأموال حقيقية | مقفل في هذه النسخة |

## حدود مهمة
- **الحجم:** يُحسب من المخاطرة (1% من الرصيد) ومسافة الوقف، باستخدام `tick_size` و`tick_value_account` من مواصفات الرمز لدى الوسيط، ولا ينزل عن الحد الأدنى `volumeMin`.
- **الربح والخسارة:** على حساب TickerAll تُحسب بعملة الحساب من سجل المنصة. الصفقات الورقية تُحسب بالـ R كما في الاختبار.
- **الذهب:** التحليل يعتمد على PAXG، وجلسته أيام العمل فقط. البيتكوين 24/7.
- **التخزين:** قاعدة البيانات والمفاتيح وكلمة مرور الحساب تُحفظ على القرص المؤقت لـ Render. عند إعادة التشغيل تُفقد، وتحتاج إعادة إدخالها. المراكز المفتوحة على المنصة تبقى محمية بوقفها وهدفها، لكن النظام لا يتعرف عليها بعد إعادة التشغيل.
- **شروط الخدمة:** راجع شروط TickerAll بخصوص التداول الآلي عبر API قبل الاعتماد عليها.
- **التحليل تعليمي وليس توصية مالية.**
