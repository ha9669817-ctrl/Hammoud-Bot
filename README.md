# بوت التوصيات (حساب تجريبي فقط)

يقرأ توصيات 4 قنوات على تيليجرام (Free Forex Signals وMaster blue وLiquidity Trader وTrade Sniper)، يدخل على الذهب بقواعد ثابتة وبصفقة واحدة فقط في كل وقت (الباقي في طابور ولا يُهمل)، ويحرّك الوقف فقط
(بعد TP1 إلى الدخول+0.1R، بعد TP2 إلى TP1، والإغلاق بالوقف أو TP3). يسجّل كل صفقة ودرسها، ويوقف تلقائياً القناة
التي تخسر فعلياً.

## الإعداد في Render (متغيرات بيئة)
`ADMIN_PASSWORD`، `TICKERALL_API_KEY`، `MT5_SERVER`، `MT5_ACCOUNT_ID`، `MT5_PASSWORD`، `SIGNALBOT_MODE=demo`،
`TG_API_ID`، `TG_API_HASH`، `TG_SESSION`، (اختياري) `TG_CHANNELS="الاسم=المعرّف,..."`.

## توليد TG_SESSION
على جهازك: `pip install telethon` ثم `python tools/telegram_login.py`. الجلسة تعادل كلمة مرور حسابك، لا تشاركها.

## ملاحظات
- التشغيل مغلق افتراضياً؛ يبدأ من زر «تشغيل» في اللوحة.
- مسار تعديل الوقف في TickerAll غير موثّق في الملفات؛ الكود يجرّب الصيغ المعقولة ويسجّل أي فشل في «آخر القرارات».
- قرص Render المجاني مؤقت: السجل يضيع عند إعادة النشر.
- النسخة القديمة محفوظة في الوسم `legacy-before-rewrite`.
