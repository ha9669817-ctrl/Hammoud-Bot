# مركز التحليل الذاتي

## الرفع على GitHub (مهم)
ارفع **الملفات الأربعة مباشرة في جذر المستودع**، وليس مجلداً يحتويها:
- `app.py`
- `requirements.txt`
- `render.yaml`
- `README.md`

المشروع كله في ملف `app.py` واحد، فلا توجد مجلدات داخلية ولا استيرادات محلية.

## النشر على Render
1. Render ← New ← Blueprint ← اختر المستودع.
2. أدخل `ADMIN_PASSWORD` (كلمة مرور اللوحة)، و`TELEGRAM_TOKEN` و`TELEGRAM_CHAT_ID` (اختياريان).
3. بعد Live افتح الرابط.

## الإعدادات من داخل الموقع
- **الأصول:** الذهب، البيتكوين، أو الاثنان معاً.
- **ربط الوسيط:** أدخل مفاتيح Binance Testnet (فيوتشرز أو سبوت) من لوحة الإعدادات، واختبر الاتصال.
- **الوضع:** ورقي (Paper) أو تجريبي (Demo). الحقيقي والـ MT5 غير مفعّلين.

## ملاحظات
- المفاتيح وقاعدة البيانات تُحفظ على القرص المؤقت لـ Render المجاني، فتُفقد عند إعادة التشغيل.
- الوقف والهدف يراقبهما التطبيق كل 15 دقيقة، لا المنصة.
- الذهب يُحلَّل عبر PAXG، وجلسته أيام العمل فقط. البيتكوين 24/7.
- التحليل تعليمي وليس توصية مالية.
